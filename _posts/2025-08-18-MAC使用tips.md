## 终端
### 添加代理
需要clash开本地代理
```shell
cat > ~/.bash_profile << EOF                      

function proxy_on() {

    export http_proxy=http://127.0.0.1:7897

    export https_proxy=\$http_proxy

    echo -e "代理已开启"

}

function proxy_off(){

    unset http_proxy https_proxy

    echo -e "代理已关闭"

}

EOF
```
可以输入`proxy_on`打开代理
### 安装[brew](https://brew.sh/)

2. 安装后会显示WARNING：需要设置环境变量才能正确使用，按照显示的设置即可

## 快捷键
### 窗口操作
`command+～` 切换同一个应用多个窗口
`command+H` 隐藏窗口（hide）
`control+上箭头`打开调度中心
`control+左/右箭头`切换桌面
`control+space`或capslock切换输入法，映射为`shift`
`control+command+F`全屏
`command+F3`显示桌面
`control+command+q`锁定桌面
`option+command+H+M`或`option+command+点击桌面空白处`收起所有窗口
设置截屏快捷键`control+option+s`
`command+backspace`删除文件
### 显示操作
`option+command+=` 放大页面
`option+command+-` 缩小页面
`option+command+8` 恢复页面
### 修改mac键位

```json
    "manipulators": [
        {
            "from": { "key_code": "left_shift" },
            "to": [
                {
                    "key_code": "left_shift",
                    "lazy": true
                }
            ],
            "to_if_alone": [
                {
                    "key_code": "spacebar",

                }
            ],

        {
            "from": { "key_code": "right_shift" },

                }

}
```
